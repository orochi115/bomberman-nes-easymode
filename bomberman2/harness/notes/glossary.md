# 命名约定（全任务共用）

源码注释用英文。名字全大写、下划线分隔，最长 40 字符。

## 前缀

- `PPU_` 画面寄存器、阴影、队列、CHR 上传
- `NMI_` 中断开关与计数
- `OAM_` 精灵缓冲（页 7）
- `JOY_` / `JOYPAD` 手柄。`JOYPAD1` 是 $4016 bit0，`JOYPAD2` 是 $4017 bit0，`JOYPAD3` 是 $4016 bit1
- `SND_` / `AUDIO_` 声音。命令经 `AUDIO_CALL` 进 bank 2
- `PAL_` 32 字节调色板缓冲
- `SCROLL_` 滚动阴影。`SPLIT_` 是精灵 0 分割画面
- `RNG_` 三字节随机数
- `MAP_` 关卡格（WRAM，行指针从 $62F3 起，步长 $20）
- `DEMO_` 演示关记录
- `MMC1_` / `CUR_BANK` / `SAVED_BANK` bank 切换

## 和第一代 `../bman.asm`、`../vars.asm` 对齐的名字

- `FRAME_CNT` 每帧加一（这里由 NMI 写，地址是 $14，不是一代的 $33）
- `JOYPAD1` 按住的键。另有 `JOYPAD1_NEW`（本帧新按下）、`JOYPAD1_OLD`
- `PPU_CTRL_BUF` / `PPU_MASK_BUF` 对应一代的 `LAST_2000` 思路，但是 $2000/$2001 的影子
- 按钮位和 NES 相同：A=$80 B=$40 Select=$20 Start=$10 上=$08 下=$04 左=$02 右=$01

## 本任务已经钉死、后面请沿用的术语

- `Z_49` 模式：0 故事，1 和 2 会走不同的关前画面。本任务没有改它的名字
- `Z_4B` 区 0–5，`Z_4C` 关 0–7，`W_04E5` 剩余命
- `W_03EF` 演示标志：0 正常，1 演示中，负值表示退出演示
- `OAM_READY`（$12）不是暂停。NMI 看到它就 DMA $0700，随后清精灵缓冲。暂停在 `UPDATE_PAUSE`，看 Start
- `SPLIT_MODE`（$31）：0 关，1 顶部分割（精灵 0 的 Y=$10），$80 低分割（Y=$90）
- 区 6 表示通关流程，不是第六张普通地图
