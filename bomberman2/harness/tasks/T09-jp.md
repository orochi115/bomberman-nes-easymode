# T09-jp：日美版差异（在 T08 之后执行）

## 范围
所有 `IF REGION_JP ... ELSE ... ENDIF` 块（`grep -n "IF REGION_JP" bank*.asm`）。

## 任务
1. 逐块确认差异类型：文字或图形数据、常量、逻辑修改、因数据长度不同而产生的地址差异。
2. 在每个块所在位置的第一个共享标签上方加注释，说明差异，例如 `; JP: ... / US: ...`。
   日版独有的标签（`JS…`、`JL…`、`JD…`）用 `jp:b:XXXX` 键命名。
3. 在笔记里汇总：美版相对日版做了哪些修改。
4. 笔记：`harness/notes/T09-jp.md`。
