# Chinese strings, processed by tools/build_text.py (text/en_strings.txt holds
# the English strings of the mod's new screens)
#
# Format: SET  ID  ROW  COL  TEXT
#   SET   screen set (tools/build_text.py SETS): the glyphs of a set are
#         uploaded into tiles that screen does not use
#   ID    ZH_<ID>; !ID is not printed by ZH_SCREEN; ID/US or ID/JP is only
#         used for that region
#   ROW   top tile row (strings are two tiles high), or - (run time)
#   COL   left tile column (32-63: the nametable at $2400), c to centre,
#         or - (run time)
#   TEXT  CJK characters are 16x16 (2x2 tiles); ASCII letters and digits use
#         the screen's 8x8 font in the bottom row; space = 8px, full-width
#         space = 16px; ◀ ▶ are 8x16 arrows; {XX} raw tile; {} empty;
#         @ only defines ZH_<ID>_ADDR
#
# CONST lines become assembler constants
