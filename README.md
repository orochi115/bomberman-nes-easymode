# Bomberman and Bomberman II (NES)

Both games are in this tree. Build either one from its own directory.
BeebAsm is the `third_party/beebasm` submodule; `git submodule update --init` fetches it, and the build scripts compile it when the binary is missing. Set `BEEBASM` to use a copy from somewhere else.

- [Bomberman II](bomberman2/README.md)
